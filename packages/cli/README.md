# forge-design CLI

Install the [Forge](https://github.com/Sebtiago/forge-design) design system builder skill for Claude Code.

```bash
npx forge-design
```

## Commands

| Command | Description |
|---------|-------------|
| `npx forge-design` | Install the skill |
| `npx forge-design install` | Install the skill |
| `npx forge-design uninstall` | Remove the skill |
| `npx forge-design info` | What Forge does |
| `npx forge-design help` | Show all commands |

## After install

```bash
claude
/forge
```
