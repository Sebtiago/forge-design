Thanks for wanting to improve Forge. Here's everything you need.

---

## What lives where

| Path | What it is |
|------|------------|
| `skills/forge.md` | The Claude Code skill — the core of Forge |
| `examples/` | Example components generated by Forge |
| `docs-site/` | The visual documentation site template |
| `tokens/` | Token file templates |

The skill file (`skills/forge.md`) is the most important file. It contains all the instructions Claude follows when you run `/forge`.

---

## How to contribute

### 1. Fork and clone

```bash
git clone https://github.com/Sebtiago/forge-design
cd forge-design
```

### 2. Install the skill locally

```bash
cp skills/forge.md ~/.claude/skills/forge.md
```

### 3. Test your changes

Run Claude Code and test with `/forge`. Go through a full flow — at minimum the "From scratch" mode which doesn't require Figma.

```bash
claude
# then type: /forge
```

### 4. Open a PR

Keep PRs focused. One change per PR.

---

## Skill file guidelines (`skills/forge.md`)

- Keep the banner and formatting rules at the top — they affect every message
- Every step must have a clear `◇` question or `✔` completion marker
- Progress bars: 16-char width, `█` filled, `░` empty
- No emoji in CLI output
- Test every flow change end-to-end before submitting

---

## Adding a new stack

To add a new framework (e.g. Angular):

1. Add the option to the **Question 2 — Stack** section
2. Add a new **Preview HTML Template** section for that stack
3. Add component generation rules for that stack's file format
4. Add an example component in `examples/[stack-name]/components/`
